## 2. 0.5.0 內容範圍

### 2.1 功能整理

Aurobox 0.5.0 的核心功能已包含以下流程：

- 包裹指派與門任務建立
- 門口裝載與狀態切換
- 機器人派送與 QR 驗證
- 揀取完成、完整結案與取消
- 返回流程與召回流程
- Dashboard 狀態查詢

本次更新重點如下：

- 將 README 內容整理為 0.5.0 版本的完整使用說明

## 3. 系統現況

### 3.1 架構現況

專案目前仍以 Flask API 為主要入口，搭配 PostgreSQL 儲存狀態資訊，並透過 FlashbotController 與 Pudu API client 與外部平台互動。背景任務與服務層負責協調流程邏輯，讓 API 入口能專注於請求與回應。

### 3.2 資料模型

目前主要模型包含：

- Door：代表門口狀態與任務資訊
- RobotState：代表機器人目前狀態
- 任務流程相關資料：由 services 與 tasks 協調管理
